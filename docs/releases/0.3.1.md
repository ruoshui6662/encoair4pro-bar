# EncoBar 0.3.1

为 OPPO Enco Air4 Pro 提供原生菜单栏电量查看和降噪、通透、关闭控制。

## 本版内容

- 修复断开后仍显示仓电量历史及时间的问题；连接后保留有效记录并接收新读数。
- 提供当前用户安装包及内置卸载工具。
- 整理源码与文档，采用 MIT 许可证，提供源码包和 SHA-256 校验。

## 安装与卸载

下载 `EncoBar-0.3.1-macos-arm64.pkg`，双击安装。应用位于 `~/Applications/EncoBar.app`，无需管理员密码。首次运行请允许蓝牙权限。

卸载入口：耳机面板「…」→「卸载 EncoBar…」。覆盖升级无需卸载，保留已有电量记录。

## 支持范围

Apple Silicon、macOS 13+，当前仅验证 Enco Air4 Pro，产品 ID `067C10`。仓电量需要开盖上报，合盖后可能显示上次有效值。

当前为 ad-hoc 构建，未做 Developer ID 签名或 Apple 公证，不承诺在其他 Mac 上通过 Gatekeeper 检查。macOS 自身的系统记录不由卸载器删除。

`SHA256SUMS.txt` 用于检查下载内容是否完整；它不是开发者签名或发布者身份认证。
