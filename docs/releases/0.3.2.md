# EncoBar 0.3.2

修复摘下、重新佩戴耳机时的模式状态与失败反馈。

- 佩戴通知与模式通知按事件类型严格区分，避免单耳状态被误读成噪声模式。
- 模式指令仍立即发送，同时读取佩戴状态。耳机未入耳且模式没有变化时，及时结束等待并提示佩戴；不把成功 ACK 当成实际成功。
- 佩戴变化后重新读取真实模式，重新戴好即可再次点击，无需重启或重新连接。
- 面板底部保留连接状态，仅在需要时给出简短反馈，没有新增设置项。

当前 Air4 Pro 实机在双耳未入耳时会 ACK 指令但不执行。此版本改善识别和反馈，不绕过固件的佩戴限制。佩戴并播放声音的对照中已观察到正常切换；未涵盖所有通话、固件或双设备组合。

Apple Silicon、macOS 13+。下载 `EncoBar-0.3.2-macos-arm64.pkg` 覆盖安装，无需先卸载，保留历史电量记录。

App 为 ad-hoc 签名，PKG 未做 Developer ID 签名和 Apple 公证。校验文件用于验证完整性。
