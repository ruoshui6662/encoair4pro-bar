# EncoBar 0.3.3

应用现在安装到 Mac 默认的“应用程序”文件夹 `/Applications`。

- 安装时按 macOS 提示输入管理员密码。
- 升级前请退出旧版。当前登录用户个人 Applications 文件夹中的已识别旧版会移至废纸篓，电量记录和偏好会保留。
- 卸载仍从面板“…”→“卸载 EncoBar…”进入；移除系统应用及安装收据时会请求管理员授权。

下载 `EncoBar-0.3.3-macos-arm64.pkg`，适用于 Apple 芯片的 Mac、macOS 13 或更新版本。

若 macOS 提示无法验证开发者，先尝试打开安装包，再到“系统设置 → 隐私与安全性”点“仍要打开”，然后重新安装。首次打开应用被拦截时也可按同样步骤处理。

App 使用 ad-hoc 签名，安装包尚未经过 Developer ID 签名和 Apple 公证。耳机功能沿用 0.3.2。
