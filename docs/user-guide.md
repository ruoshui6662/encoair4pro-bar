# 使用、更新与卸载

## 安装

在仓库 Releases 下载适用于 Apple Silicon 的 PKG。双击安装后，应用位于 `~/Applications/EncoBar.app`；在访达“前往文件夹”中输入 `~/Applications` 即可找到。安装不要求管理员密码，不添加登录项或守护服务。

先将 OPPO Enco Air4 Pro 与 Mac 配对并连接，再打开应用并允许蓝牙权限。点击菜单栏耳机图标打开面板；外部点击或 Escape 收起。重复打开应用也会显示面板。

当前公开构建使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证。在其他 Mac 上的 Gatekeeper 行为尚未验证。

## 电量和模式

模式按钮的选中状态来自耳机回读。佩戴检测、耳机固件及多设备连接可能影响指令是否生效。

Air4 Pro 双耳未入耳时可能回复成功但不执行切换。此时面板提示“请佩戴后切换”，结束等待并保留实际模式；重新戴好后可直接再次点击。播放声音并非应用的切换禁用条件。

耳机仓电量通常需要双耳放回盒内并保持开盖。没有读到有效值时显示 `—`；获得有效读数后保存在本机。取出耳机或合盖后可能没有新读数，此时显示上次有效值，悬停可查看时间。断开连接时所有电量均隐藏，重连后恢复该设备的有效仓记录。

面板打开时每 5 秒查询，收起后每 30 秒查询，通知到达立即更新。百分比不变不表示没有刷新。

## 更新

退出旧实例后运行新版 PKG，覆盖同一安装路径。覆盖更新保留用户偏好；不需要先卸载。请只运行一个 EncoBar 实例。

## 退出与卸载

- 退出：面板右上角「…」→「退出 EncoBar」。
- 卸载：同一菜单选择「卸载 EncoBar…」，在独立确认窗口中确认。

卸载器退出 EncoBar，处理当前用户的本应用及卸载器偏好、缓存和保存状态、应用支持目录、蓝牙授权和当前用户的安装收据，并将应用及数据移至废纸篓。取消不会执行清理；失败项目会列出。

路径固定，不会按名称搜索源码或其他应用。直接删除 App 本体不会自动清理偏好。macOS 自身的安装历史、系统日志由系统管理；开发源码、编译缓存及手动保存的诊断文件也不属于普通安装的数据。

## 故障排查

- 未连接：先在系统蓝牙设置中连接耳机，再从菜单选择重新连接。
- 没有权限：系统设置 → 隐私与安全性 → 蓝牙中允许 EncoBar。
- 仓电量未知：双耳入盒、开盖后等待自动读取。卸载重装会清除历史，需重新读取一次。
- 模式没有变化：确认耳机佩戴检测有效；按钮只会在实际回读匹配时确认成功。
- 控制通道超时：退出其他副本，重新连接耳机。必要时重启 Mac 蓝牙，但这会短暂断开其他蓝牙设备。
