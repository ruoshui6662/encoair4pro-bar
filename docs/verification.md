# 验证范围

本机验证平台：Apple Silicon、macOS 26.7.1、OPPO Enco Air4 Pro（产品 ID `067C10`）。不包含其他机型、全部固件或全部显示器布局的兼容保证。

## 已验证

- SDP 动态发现厂商控制通道，模式查询、设置与新查询回读。
- 通透 → 降噪 → 关闭 → 恢复原模式完整通过。一次佩戴条件有效的测量中，指令至协议确认耗时 86–203 ms；不等于声学切换延迟的测量。
- 左右耳电量、双耳入盒开盖后的仓电量、仓记录持久化与未知报告不覆盖历史。
- 面板内与后台自动查询，批量订阅无回应时逐事件订阅。
- 断开时隐藏历史仓电量，连接后显示有效记录；模型回归涵盖未知值、有效通知和重连更新。
- 正常菜单栏模式下的面板显示、打开和收起；几何回归涵盖负坐标副屏。
- 当前用户 PKG 安装与覆盖升级、嵌套签名检查、卸载确认及取消流程。

## 自动检查

`bash scripts/test.sh` 运行协议、状态、显示规则与发布工具检查。模型测试仅替换物理蓝牙边界和授权查询，保留实际解析、计时器与确认逻辑。

`bash scripts/release.sh` 生成发布产物并执行源码清单、隐私字段、版本和校验文件检查。原始本机日志与开发过程记录不随源码包发布。

当前版本本地通过 28 项核心检查、模型回归和 7 项发布工具测试。0.3.1 目录整理时，源码 ZIP 在不含原工作目录缓存、路径带空格的新目录中完成测试、构建和 PKG 打包。另检查了安装包内容、主应用与卸载器版本、嵌套 ad-hoc 签名、MIT 声明，以及旧构建文件不会混入新包。

0.3.2 排查实测：双耳摘下时佩戴回报 `1/1`，通透指令收到成功 ACK，但多次模式查询保持关闭；戴好并播放声音时回报 `3/3`，切换通透成功。过程中还观察到短暂单耳未入耳与模式变化同时发生，不能据此断定所有播放问题均由佩戴引起。修复版已实测在双耳未入耳且模式不变时及时结束等待，面板显示佩戴提示。回归另涵盖佩戴／适配事件不误改模式、未知佩戴不阻塞成功回读、重新戴好可立即再试，以及新入耳通知覆盖较旧查询的顺序。

0.3.2 已覆盖安装并实机完成通透 → 降噪 → 关闭 → 恢复原模式，用户确认保持播放。随后连续点击也均回读成功，本轮耗时范围 69–187 ms（指令至协议确认，非声学延迟）。普通运行已关闭诊断参数。
